# Financial_Transaction_Analytics
End-to-end financial transaction analytics project analyzing 1.2M+ transactions using Python, PostgreSQL, Excel, and Power BI to uncover spending patterns, customer behavior, and fraud risk.
## 📊 Veri Seti (Dataset)
Bu projede kullanılan veri seti, finansal işlemlerde dolandırıcılık tespiti (fraud detection) analizleri yapmak üzere tasarlanmıştır. Veri setine ve detaylı incelemelerine [Financial Fraud Detection Dataset - Kaggle](https://www.kaggle.com/code/kozhamuratovaa/financial-fraud-detection-dataset) bağlantısı üzerinden ulaşabilirsiniz.
