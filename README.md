# Financial_Transaction_Analytics
End-to-end financial transaction analytics project analyzing 1.2M+ transactions using Python, PostgreSQL, Excel, and Power BI to uncover spending patterns, customer behavior, and fraud risk.
## 📊 Dataset
The dataset used in this project is designed for fraud detection analysis in financial transactions. You can access the dataset and a detailed analysis of it via the following link: [Financial Fraud Detection Dataset - Kaggle](https://www.kaggle.com/code/kozhamuratovaa/financial-fraud-detection-dataset).
